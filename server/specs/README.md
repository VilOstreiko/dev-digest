# server specs

Feature specs for `server/`, written before and kept current during implementation.
Read the relevant spec before implementing a feature.

## Conventions

- One spec per feature: `<milestone>-<feature>.md` (e.g. `m1-severity-filter.md`).
- Add a line to the index below when you add a spec.
- Update the spec when the implementation diverges from it.

## Template

```md
# <Feature>

## Goal
## Scope
## Acceptance criteria
## Out of scope
```
